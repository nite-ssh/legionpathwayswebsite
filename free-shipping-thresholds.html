Free Shipping Thresholds: How to Set Them Without Losing Margin

By Nitesh Poudel · 6 min read

A free shipping threshold is one of the few pricing levers that can lift both conversion and average order value at the same time — but only if it's set with actual order data, not a round number that felt right.

Set the threshold from your own data

Look at your current average order value and set the threshold slightly above it — typically 20-30% higher — so it's achievable but still nudges people to add one more item rather than feeling out of reach.

Show progress toward the threshold

A visible progress indicator ("add $12 more for free shipping") in the cart consistently outperforms simply stating the threshold in a banner, because it turns a static rule into an active nudge at the exact moment someone is deciding whether to add another item.

Model the margin impact before launching

Calculate what percentage of orders will now qualify for free shipping at the new threshold, and what that costs against the expected lift in average order value. A threshold that's too low can quietly erode margin even while average order value looks like it's improving.

Key takeaways

  • Set the threshold slightly above your current average order value, not an arbitrary round number.
  • A visible progress bar in the cart outperforms a static banner.
  • Always model the margin trade-off before changing the threshold.
